### 11.09.2026 — Ярлык открывал браузер вместо приложения
- **Причина**: ярлык создан через «Добавить на главный экран» (закладка), а не через нативный диалог установки PWA (beforeinstallprompt / «Установить приложение»).
- **Признаки настоящей установки**: WebAPK в списке приложений, сплэш-экран, полноэкранный режим без адресной строки, офлайн-работа.
- **Требование Chrome**: перед beforeinstallprompt нужно ~30 сек взаимодействия со страницей.
- **Следующий уровень (по запросу)**: APK через PWABuilder + проверка домена assetlinks.json через репозиторий shamgonov.github.io.

### 11.09.2026 — Маршрут APK (PWABuilder): состав пакета и подводные камни
- **Сборка**: pwabuilder.com → Package For Stores → Android. Архив «Google Play package» содержит: assetlinks.json, ServiceCRM.apk (установка на телефон), ServiceCRM.aab (для магазинов), signing.keystore + signing-key-info.txt (подпись).
- **ПРАВИЛО**: signing.keystore и signing-key-info.txt НЕ пушить в GitHub никогда. Резервная копия: E:\keystore-backup.
- **Домен**: создан репозиторий shamgonov.github.io (Public), запушен .well-known/assetlinks.json. Pages для user-репозитория включается: Settings → Pages → Deploy from branch → main / (root).
- **ЛОВУШКА**: Jekyll (включён в Pages по умолчанию) вырезает папки с точкой, поэтому .well-known отдавал 404. Фикс: пустой файл .nojekyll в корне репозитория shamgonov.github.io.
- **Проверка домена**: рабочая ссылка только https://shamgonov.github.io/.well-known/assetlinks.json (корень домена всегда 404 — это норма, index.html там нет).
- **Статус на момент записи**: APK собран, assetlinks запушен, ждём публикацию Pages и проверку домена Android-ом.

### 11.09.2026 — Сводка способов установки (итог исследования)
- Ярлык «Добавить на главный экран» = закладка, открывает браузер. Не приложение.
- WebAPK (нативный диалог Chrome) = полноэкранно, но ненадёжно: требует активного SW, GMS, ломается старым кэшем.
- TWA APK (PWABuilder) = настоящее приложение в списке приложений; контент живёт на GitHub Pages и обновляется деплоями menu.bat без пересборки APK; пересборка нужна только при смене иконки/имени/домена.

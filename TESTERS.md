# ServiceCRM — описание проекта и план тестирования

## Что это такое

ServiceCRM — приложение для сервисной компании: заявки на ремонт/изготовление/сервис, календарь выездов, сотрудники, финансы и уведомления. Работает как сайт и как приложение на телефоне (устанавливается на главный экран, обновляется само). Данные хранятся в облаке Firebase; без интернета приложение показывает сохранённое и отправляет изменения, когда связь вернётся.

## Кто и как заходит

- **Владелец (Дмитрий)** — первое устройство. Видит панель «👑»: может войти «как» любая роль для проверки и открыть «👥 Управление» (заявки на приём, сотрудники, роли).
- **Сотрудник** — на новом устройстве вводит имя и жмёт «Запросить доступ». Владелец принимает и назначает роль. Дальше вход по PIN (если задан).
- **Роли и права** — в «Управлении → Роли» матрица прав (16 штук: смотреть/создавать/менять/удалять/отменять заявки, история, календарь, задачи, закупки, отчёты, финансы и т.д.). У администратора все права.

## Основные экраны

- **📋 Заявки** — список заявок с фильтрами (мои/просроченные/статусы). Поиск, карточка заявки, создание «＋».
- **Карточка заявки** — клиент, адрес, время, сумма, статус, исполнитель, фото, платежи, этапы (для «с изготовлением»), схема маршрута и «📜 История» всех действий.
- **📅 Календарь** — заявки по дням, конфликты времени (одна точка — один исполнитель в одно время).
- **✅ Мои задачи** — что делать сегодня/завтра у исполнителя.
- **🛒 Закупки** — материалы по заявкам, отметка «куплено» (показывает, сколько уже выдано денег на материалы).
- **📊 Отчёты** — статистика, выручка, доля исполнителя, экспорт в CSV (файл Excel).
- **⚙️ Админ / 👥 Управление** — база (адрес склада), Storage, тестовые заявки, специализации, финансы (вкладка «Финансы» + закрытие кассы), шаблоны работ, сотрудники и роли.
- **👤 Профиль** — фото, контакты, специализация (выбор из справочника), PIN, настройки уведомлений.

## Как живёт заявка (типы и статусы)

- **Типы**: стандартная, «с изготовлением» (этапы: замер → изготовление → монтаж, у каждого срока: дата / «по готовности» / «по договорённости»), сервисная (выезд).
- **Путь**: Новая → (взять в работу) Согласована → «Приступил» (В работе) → Выполнено (обязателен фотоотчёт) → Оплачено. Можно: Перенести, Отменить (с причиной, скрыта из календаря/задач).
- **Остаток и касса**: при переводе «в выполнено» с долгом — окно закрытия: состав работ, итог, оплачено, остаток; кнопки «Заказчик внёс остаток» (создаёт платёж) и «Оплачено полностью».
- **Платежи**: аванс / частичный / полный / «выдать на материалы» (не входит в остаток). Баланс считается сам.
- **Схема выполнения**: точки маршрута (заказчик, подрядчик, поставщик, объект) с временем и статусом; «🚗 Выехал» → «Прибыл»; при «Прибыл» на поставщике с выданными деньгами — подтверждение суммы закупки.
- **История**: каждое действие пишется в журнал заявки (кто, когда, что; платежи — суммы/метод; статусы — «из → в»; правки — «было → стало»). Смотрится по тапу на строке; доступен по праву «Просмотр истории заявок».

## Уведомления

Приложение само сообщает о событиях: новая заявка, назначили/сняли меня, перенос, выполнение, просрочка, этап готов, платёж, отмена, «Скоро выезд» (за час), «Завтра N заявок» (после 18:00). На пунктах меню появляются красные счётчики. В профиле включаются/выключаются: системные уведомления, звук, вибрация, режим «не беспокоить» по часам. При убитом приложении пушей пока нет (в плане).

## Тестовые заявки и специализации

- **Тестовые заявки** (галочка «тестовая» в карточке) — скрыты из списков, когда в админке выключено; НИКОГДА не попадают в отчёты и финансы.
- **Специализации** — справочник в «Управлении → Роли» (добавить/переименовать/удалить). Сотрудники выбирают их в своём профиле. Переименование обновляет профили; при удалении — предупреждение «используют N сотрудников».

# Задачи для тестировщиков

Формат: что сделать → что должно получиться. Отмечать: ок / не ок + что не так.

## 1. Вход и доступы
1.1. Новое устройство: ввести имя → «Запросить доступ» → у владельца в «Управлении» появилась заявка → принять с ролью «Исполнитель» → на устройстве сотрудник вошёл.
1.2. Сотруднику задать PIN (профиль → PIN) → разлогин → вход только после верного PIN; неверный — подсказка.
1.3. Владелец: панель «👑» → войти как «Исполнитель» → меню и кнопки соответствуют роли (нет «Админа», есть «Мои задачи»).

## 2. Права
2.1. Создать роль «Тест» без права «Отмена заявок» → войти как эта роль → в карточке нет «❌ Отменить заказ», отмена через селект статуса тоже заблокирована.
2.2. Без права «Просмотр истории заявок» — секция «📜 История» не видна; с правом — видна.
2.3. Без права «Финансы (платежи)» — нет кнопок «＋ Приход/＋ Выдать».

## 3. Заявки: полный путь
3.1. Создать стандартную заявку (клиент, телефон, адрес, дата, время, сумма) → появилась в списке и календаре, статус «Новая».
3.2. Исполнитель: «✅ Взять в работу» → «🔧 Приступил» (заявка уходит в «Мои задачи» на сегодня).
3.3. Попытаться «Выполнено» без фото → предупреждение «нужен фотоотчёт»; добавить фото → закрыть удалось.
3.4. Перенести заявку на другой день → в календаре переехала; исполнитель получил уведомление «Перенос заявки».
3.5. Отменить с причиной → бейдж «отменена», скрыта из календаря и «Моих задач», карточка серая.

## 4. Типы и этапы
4.1. Создать «С изг.»: этапы создались сами; «▶ Приступить» и «✅ Этап готов» по очереди; срок этапа переключается (дата/по готовности/по договорённости) и сохраняется; название этапа можно исправить с карандаша.
4.2. Готов «Изготовление» → у этапа «Монтаж» загорелась дата (если срок «по готовности»); уведомление «Этап готов» следующему исполнителю.
4.3. Сервисный тип → один этап «Выезд».

## 5. Платежи и финансы
5.1. Аванс 5000 → баланс уменьшился; в истории заявки событие «Получен платёж» с суммой и методом.
5.2. «＋ Выдать на материалы» → в «Закупках» у позиции показано «выдано … ₽»; баланс НЕ изменился.
5.3. Закрытие с долгом: у заявки остаток → «Выполнено» → окно закрытия (итог/оплачено/остаток); «Заказчик внёс остаток» → платёж «при закрытии», заявка «Выполнено».
5.4. Админка → «Финансы»: фильтр по датам; суммы сходятся с балансами; «Отчёт CSV» открывается в Excel, секция «ПЛАТЕЖИ» есть.

## 6. Схема маршрута
6.1. У заявки «С изг.» → «🗺 Схема»: точки создались (заказчик/подрядчик/поставщик/объект), проставилось время по этапам.
6.2. «🚗 Выехал» → статус «в пути» + время; «Прибыл» → «на месте». Уведомления «Выезд»/«Прибытие».
6.3. На точке поставщика с «выдать на материалы» → «Прибыл» → модалка подтверждения суммы закупки (сумма совпадает).
6.4. База в админке + адреса заявок → «Схема маршрута» строится (при наличии интернета/ключей карт).

## 7. История заявки
7.1. Совершить действия (взял, статус, платёж, этап, доп. работа, отмена) → в «📜 Истории» все события, свежие сверху, время/дата и кто.
7.2. Тап по строке — раскрываются детали (сумма/метод, «из → в», «было → стало» при правке цены/даты/адреса).
7.3. Отредактировать заявку (цена, дата, адрес) → событие «Правка заявки» с «поле: было → стало».

## 8. Уведомления и бейджи
8.1. На втором телефоне (сотрудник): назначить ему заявку → через пару секунд системное уведомление «Назначена заявка» + красный счётчик на «Моих задачах» (не на «Заявках»).
8.2. Открыть нужный экран → счётчик на нём исчез, на других остался.
8.3. Профиль: выключить «Системные» → только счётчик; включить «Не беспокоить» на текущий час → без звука.
8.4. В 17:59+ на телефоне с заявками на завтра — одно уведомление «Завтра N заявок» (не повторяется).

## 9. Офлайн
9.1. Выключить интернет → баннер «Нет сети»; создать/изменить заявку → работает локально (с пометкой «в очереди»).
9.2. Включить интернет → «Синхронизировано»; изменения видны на втором устройстве.

## 10. Модальные окна (регресс бага)
10.1. Открыть «＋ Приход» или «❌ Отменить заказ», ввести текст → подождать ~70 секунд → окно ОТКРЫТО, текст на месте; сохранить — сохранилось.
10.2. В открытом окне платёжной модалки на втором устройстве изменить ЛЮБУЮ заявку → окно не закрылось.

## 11. Тестовые заявки и специализации
11.1. Создать галочку «тестовая» → выключить «Показывать тестовые» в админке → скрыта везде; отчёты/Финансы не изменились.
11.2. Админка «Управление → Роли» → «🛠 Специализации»: добавить 2 → в профиле сотрудника появились чипы → выбрать → «Сохранить» → выбор остался.
11.3. Переименовать → у сотрудников обновилось; удалить используемую → предупреждение «используют N сотрудников».

## 12. Календарь
12.1. Две заявки на одно время одному исполнителю → предупреждение о конфликте; владелец может «Всё равно записать».
12.2. Заявка без времени → в календаре в блоке «Без времени».

## 13. Отчёты
13.1. «📊 Отчеты»: сумма = сумма выполненных; доля исполнителя = % от его закрытых заявок.
13.2. CSV: открывать в Excel — русские буквы без кракозябр, даты ДД.ММ.ГГГГ.

## Что проверять в первую очередь (свежие правки)
1. Модальные окна не закрываются сами (п.10).
2. История: детали раскрываются, правки видны «было → стало» (п.7).
3. Специализации есть в «Управлении → Роли» (п.11).
